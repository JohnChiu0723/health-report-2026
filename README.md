# 健康檢查報告 2026 - 台南市立醫院

## 專案簡介

這是一個互動式健康報告網頁，將台南市立醫院的健康檢查報告轉換為精美的視覺化儀表板。

## 特色功能

- 📊 **數據視覺化**：使用 Chart.js 呈現 3 年數據趨勢
- 🎨 **奶油色系主題**：溫暖舒適的視覺設計
- 📱 **響應式設計**：手機、平板、電腦完美支援
- 💡 **改善建議**：具體可執行的每日行動指南
- 📅 **時間軸規劃**：預期效果與追蹤時程

## 技術架構

- **前端**：純 HTML/CSS/JavaScript
- **圖表庫**：Chart.js
- **部署**：GitHub Pages

## 本地測試


## 部署到 GitHub Pages

1. 推送倉庫到 GitHub
2. 進入倉庫設定 > Pages
3. 選擇 `main` 分支的根目錄
4. 等待幾分鐘後即可存取

## 報告重點

### 正常指標 ✅
- 血壓：104/73 mmHg
- BMI：20.17
- 血糖：93 mg/dl
- 肝功能、腎功能、尿酸皆正常

### 需關注指標 ⚠️
- **LDL-C 偏高**：125 mg/dl（參考值 <100）
- **紅血球數偏高**：555（女性參考值 370-550）
- **MCV 偏低**：71.5（參考值 80-99）→ 疑似海洋性貧血

### 醫療建議
建議安排血液科門診追蹤，進行地中海貧血基因檢測。

## 改善計劃

1. **飲食調整**：減少飽和脂肪，增加膳食纖維
2. **運動計劃**：每週 150 分鐘中等強度運動
3. **醫療追蹤**：1 個月內安排血液科門診
4. **生活習慣**：充足睡眠、減少壓力

本專案僅供個人使用，報告數據來源：台南市立醫院（委託秀傳醫療社團法人經營）
